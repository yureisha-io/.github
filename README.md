# yureisha-io/.github

Organization-wide defaults for [yureisha-io](https://github.com/yureisha-io):

- `profile/README.md`: the organization's public profile page.
- `SECURITY.md`, `SUPPORT.md`: default community health files for every repository in the organization that doesn't
  have its own.
- `assets/`: the organization avatar (`org-avatar.png`, 1024×1024) and the lockups used on the profile page. They are
  copies of the Yureisha brand kit; the brand kit is the source of truth.
