# Getting help with Yureisha

Yureisha is in development and has not been released, so there is no support channel yet. The help pages will be
at yureisha.io/support once the site is live.

- **What changed in each version:** [yureisha-io/releases](https://github.com/yureisha-io/releases) (empty until the
  first release)
- **Security issues:** please follow [SECURITY.md](SECURITY.md) and report privately.

Once a Mac App Store build exists, purchases (refunds, billing) will be handled by Apple through
[reportaproblem.apple.com](https://reportaproblem.apple.com).
